### 1. @ 사용할 수 있도록
### @를 /src 디렉토리로 바꿔서 쓸 수 있게 하겠다.

```javascript
export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: [
      {find: '@', replacement:path.resolve(__dirname, 'src')}
    ] 
  }
})
```
