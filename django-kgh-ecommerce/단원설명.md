## 1. 문서화를 시키는 이유

- 프론트엔드/백엔드 협업에 유리
    - API 명세서를 GUI로 보여줘서 프론트엔드 개발자가 백엔드 코드 없이도 어떤 API가 있고, 어떻게 요청해야 하는지 쉽게 확인 가능

- API 테스트 기능 제공

## 2. drf_spectacular 기본 세팅

1. INSTALLED_APP에 추가가

```python
INSTALLED_APP = [
    ...
    "drf_spectacular"
]
```

2. REST_FRAMEWORK에  "DEFAULT_SCHEMA_CLASS": "drf_spectacular.openapi.AutoSchema" 추가

```python
REST_FRAMEWORK = {
    ...
    "DEFAULT_SCHEMA_CLASS": "drf_spectacular.openapi.AutoSchema"
}
```
